# Multi-factor authentication (MFA)

Every account must enrol an authenticator app within 7 days of the first sign-in.
SMS codes are allowed only as a backup method.
A lost or replaced phone must be reported the same day by opening a ticket with priority "high".
The help desk removes the old device and sends a one-time enrolment link to the staff member's manager.
Never approve an MFA prompt you did not start; report unexpected prompts as a security incident.
